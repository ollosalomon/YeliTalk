🗣️ YeliTalk — Application de discussion éducative et communautaire
🚀 Description

YeliTalk est une application mobile de messagerie et de collaboration éducative développée avec Flutter.
Elle permet aux apprenants, formateurs et startups de communiquer, partager des ressources et collaborer en temps réel au sein de la communauté YeliTech.

L’objectif de YeliTalk est de créer un espace numérique simple, fluide et sécurisé pour échanger autour de la formation, de l’innovation et des projets technologiques.

✨ Fonctionnalités principales

💬 Messagerie instantanée : discussions privées et de groupe, avec envoi de texte, image et document.

🏫 Canaux communautaires : espaces thématiques (formation, IA, cloud, data, etc.) ouverts aux membres YeliTech.

🧑‍🏫 Groupes d’apprentissage : communication directe entre formateurs et apprenants.

📰 Actualités & annonces : diffusion d’informations depuis la plateforme YeliTech (événements, opportunités, challenges).

🧠 Profils utilisateurs : chaque membre possède un profil personnalisé avec son parcours, ses compétences et ses projets.

🔔 Notifications en temps réel : alertes pour nouveaux messages, invitations et annonces.

🛠️ Technologies utilisées

Frontend : Flutter (Dart)

Backend : FastAPI (Python) / Node.js (selon environnement)

Base de données : PostgreSQL + MongoDB

Authentification : JWT / OAuth2

Stockage de fichiers : MinIO

Monitoring & Analytics : Prometheus + Grafana

📱 Design & UX

Interface moderne, minimaliste et intuitive.

Palette de couleurs inspirée de l’identité YeliTech (bleu, blanc et orange).

Design responsive et compatible Android & iOS.

🧑‍💻 Objectif du projet

Créer une application de communication 100 % africaine au service de l’éducation, des startups et de l’innovation, pour connecter les talents et accélérer les projets technologiques au sein du réseau YeliTech.

🔧 Installation (développement)
# 1. Cloner le dépôt
git clone https://github.com/<ton-username>/YeliTalk.git
cd YeliTalk

# 2. Nettoyer et installer les dépendances
flutter clean
flutter pub get

# 3. Lancer l'application
flutter run
